деталь: сигнализация тревоги
в начале: заключённый стоит рядом с дверью тюрьмы
в начале: охранник стоит перед камерой наблюдения
событие: камера начинает трястись относительно пола (с 0 по 5 секунду)
событие: камера приближается к лицу охранника с 0 по 3 секунду
событие: камера резко отъезжает в сторону камеры наблюдения с 3 по 5 секунду
событие: сигнализация тревоги включается и издает звук (с 0 по 5 секунду)
событие: охранник хмурится (с 0 по 1 секунду)
событие: охранник злится (с 1 по 2 секунду)
событие: охранник смотрит на камеру наблюдения (с 2 по 3 секунду)
событие: охранник машет рукой в сторону камеры наблюдения (с 3 по 4 секунду)
событие: заключённый бежит из двери тюрьмы (с 0 по 5 секунд)
